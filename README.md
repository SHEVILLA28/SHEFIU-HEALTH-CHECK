# SHEFIU Health Check

Android health-check prototype designed for a Samsung/Android phone.

## Build

This project is configured for Android Gradle Plugin 9.3.1 and Gradle 9.6.1. The included GitHub Actions workflow builds a debug APK on a GitHub-hosted runner and uploads the APK as a workflow artifact.

## Important medical limitation

The camera fingertip pulse estimate is experimental and is not clinically validated. It must not be treated as a diagnosis or a replacement for a medical device or clinician. Manual blood-pressure values are user-entered readings from an external device.

Never put API keys, passwords, tokens, private credentials, or personal health records in this public repository.


Build verification checkpoint: medicine information screen and health app icon are included; debug APK is built by GitHub Actions.
